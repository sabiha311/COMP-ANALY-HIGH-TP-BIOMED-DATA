# Description
This project analyzes a human protein-protein interaction (PPI) network by:
1. Constructing a graph from an interaction dataset.
2. Calculating:
   - Node degree and clustering coefficient.
   - Average clustering coefficient of the network.
3. Plotting the degree distribution to evaluate scale-free network properties.
4. Comparing shortest path length distributions between two protein sets using the Wilcoxon test.

# Input Files 

- Human-PPI.txt 
- protein-list1.txt
- protein-list2.txt
# How to Run the Code
1. Upload the files to your Google Colab session.
2. Open and run `Assignment_5.ipynb` in Google Colab.
3. Make sure the data file paths match the uploaded files.
4. The analysis results and plots will be displayed and optionally saved.
